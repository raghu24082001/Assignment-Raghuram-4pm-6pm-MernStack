java script basics

Introduction to JS

  • JavaScript is a high level interpreted programming language
  • Used to make web pages interactive and dynamic

What JavaScript can do?

  • Show alerts and messages
  • Manipulate HTML and CSS content
  • Handle events like clicks and form submissions
  • Call APIs
  • Validate user input
  • Build full applications

Variables

  • Used to store data values
  • Declared using var, let, or const
  • var is function-scoped
  • let and const are block-scoped
  • const cannot be reassigned

Example for var

var x = 10; x = 50; var x = 40; console.log(x);

Example for let

let y = 10; y = 50; console.log(y);

Example for const

const z = 10; console.log(z);

Data Types

  • Primitive: String, Number, Boolean, Null, Undefined, Symbol
  • Non-Primitive: Object, Array, Function

Array Methods

  • push()
  • pop()
  • shift()
  • unshift()
  • map()
  • filter()
  • reduce()

Example

let arr = [1,2,3,4,5]; let sum = arr.reduce((a,b) => a+b, 0); console.log(sum);

Functions

  • Function Declaration
  • Function Expression
  • Arrow Function

Arrow Function Example

const add = (a,b) => a + b; console.log(add(5,3));
