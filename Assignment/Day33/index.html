Node.js Interview Questions

1. What is Node.js?

Node.js is an open-source, cross-platform runtime environment that allows developers to run JavaScript on the server side. It uses an event-driven, non-blocking I/O model which makes it lightweight and efficient.

2. Is Node.js a framework?

No, Node.js is not a framework. It is a runtime environment for executing JavaScript code outside the browser. Frameworks like Express.js are built on top of Node.js.

3. What is V8 Engine?

The V8 Engine is Google's open-source JavaScript engine written in C++. It compiles JavaScript code directly into machine code, making execution fast. Node.js uses the V8 engine to run JavaScript.

4. What is NPM?

NPM (Node Package Manager) is the default package manager for Node.js. It is used to install, manage, and share reusable code packages (modules).

5. What are modules in Node.js?

Modules are reusable blocks of code whose existence does not accidentally impact other code. Node.js has built-in modules (like fs, http) and also supports custom and third-party modules.

6. What is Non-blocking I/O?

Non-blocking I/O means that operations like reading files or network requests do not stop the execution of the program. Instead, callbacks, promises, or async/await are used to handle results when ready.

7. What is Blocking vs Non-blocking?

Blocking: Code execution stops until the operation completes.

Non-blocking: Code execution continues while the operation runs in the background.

8. What is process object?

The process object is a global object in Node.js that provides information and control over the current Node.js process. It allows access to environment variables, command-line arguments, and methods like process.exit().
