React useEffect Notes

1. What is useEffect?

Useeffect is a react hook its a special function used to handle special fucction. Useeffect will render when your component is render your useeffect is render next to tht component. In class component we handle life cycle methods same process happend in functional component. use effect run based on dependency.

2. What is Dependency Array?

Dependency array is used to control when useEffect runs. If any value in the array changes, the effect will run again.

3. What is without Dependency Array?

If useEffect is used without a dependency array, it runs every time the component re-renders.

4. What is Empty Dependency Array?

If we pass an empty array [], useEffect runs only once when the component loads (initial render).

5. What is fetch?

fetch is a JavaScript function used to get data from an API or server. It sends a request and receives a response, usually in JSON format.
